# Recipe App — Requirements

## User Stories

1. As a new user, I want to create an account with my email and password, so that I can save and manage my own recipes.

2. As a returning user, I want to log in with my email and password, so that I can access my saved and private recipes.

3. As a user, I want to log out of my account, so that my session is no longer active on the device I'm using.

4. As a user, I want to create a recipe with a title, description, ingredients, and preparation steps, so that I can document a dish I want to remember or share.

5. As a user, I want to specify a quantity and unit for each ingredient, so that I can accurately reproduce the recipe later.

6. As a user, I want to write my preparation steps in order, so that I can follow a clear sequence when making the dish.

7. As a user, I want to add images to my recipes and individual preparation steps, so that I can show what the finished dish, technique, or intermediate result looks like.

8. As a user, I want to add tags to a recipe, so that I can categorize it and find it more easily later.

9. As a user, I want to set a default serving size for a recipe, so that ingredient quantities have a clear baseline to scale from.

10. As a recipe owner, I want to edit my recipes, so that I can fix mistakes or improve them over time.

11. As a recipe owner, I want to delete a recipe, so that I can remove recipes I no longer want.

12. As a recipe owner, I want to see all my recipes, so that I can manage my collection in one place.

13. As a guest, I want to browse public recipes without creating an account, so that I can explore the app before deciding whether to sign up.

14. As a user, I want to search for recipes by title, so that I can quickly find a specific recipe.

15. As a user, I want to search for recipes by ingredient, so that I can find recipes that use ingredients I already have.

16. As a user, I want to filter recipes by tag, so that I can find recipes that fit my needs.

17. As a user, I want to adjust a recipe's ingredient quantities based on how many people I'm cooking for, so that I don't over- or under-prepare food.

18. As a recipe owner, I want to mark a recipe as private, so that only I can view it.

19. As a recipe owner, I want to mark a recipe as public, so that other users and guests can discover and view it.

20. As a user, I want to bookmark a public recipe, so that I can find it again easily.

21. As a user, I want to remove a bookmark, so that my saved list only contains recipes I still care about.

22. As a user, I want to view my bookmarked recipes, so that I can quickly access recipes I've saved.

23. As a recipe owner, I want to see my recently deleted recipes, so that I can review what I've removed.

24. As a recipe owner, I want to recover a deleted recipe, so that I can restore something I removed by mistake.

25. As a user, I want to stay logged in across multiple devices, so that I can access my recipes from different devices.

26. As a user, I want to see my active sessions, so that I can confirm which devices have access to my account.

27. As a user, I want to log out a specific session, so that I can revoke access from a device I no longer trust.

28. As a user, I want to share a public recipe with others, so that I can pass along something useful or delicious.

## Out of Scope for v1

- Custom bookmark collections or folders
- Cooking-frequency analytics
- Dedicated social-media share previews
- Advanced ingredient-matching recommendations
